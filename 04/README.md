## Описание реализации

### scoring.py

Модуль содержит две основные функции:

- **`get_score(store, phone, email, birthday, gender, first_name, last_name)`** — рассчитывает скоринговый балл на основе переданных данных. Использует кэш через `store.cache_get/cache_set`. При недоступности хранилища продолжает работать, пересчитывая балл.

- **`get_interests(store, cid)`** — получает интересы пользователя по его CID из персистентного хранилища через `store.get`. При недоступности хранилища поднимает исключение.

### store.py

Класс `Store` реализует общение с Redis:

- **Переподключение**: при разрыве соединения пытается переподключиться `retry_times` раз (по умолчанию 3).
- **Таймауты**: `socket_timeout` и `socket_connect_timeout` предотвращают "залипание" запросов.
- **`cache_get/cache_set`**: методы для кэша — молча возвращают `None` или игнорируют ошибку при недоступности хранилища.
- **`get/set`**: методы для персистентного хранилища — поднимают исключение при недоступности.

```python
from store import Store

# Создание хранилища с настройками
store = Store(
    host="localhost",
    port=6379,
    db=0,
    retry_times=3,          # Количество попыток переподключения
    socket_timeout=5.0,     # Таймаут запроса в секундах
    socket_connect_timeout=5.0,  # Таймаут подключения в секундах
)

# Кэш (не падает при ошибке)
store.cache_set("key", "value", ttl=3600)
result = store.cache_get("key")  # None при ошибке

# Персистентное хранилище (падает при ошибке)
store.set("i:cid123", '["sport", "music"]')
result = store.get("i:cid123")  # Exception при ошибке
```

### conftest.py — декоратор @cases

Декоратор для параметризации тестов разными тест-векторами:

```python
from conftest import cases

@cases([
    {"phone": "+79991234567", "email": None, "expected": 1.5},
    {"phone": None, "email": "test@example.com", "expected": 1.5},
    {"phone": "+79991234567", "email": "test@example.com", "expected": 3.0},
])
def test_score_calculation(self, phone, email, expected):
    store = MockStore()
    result = get_score(store, phone=phone, email=email)
    assert result == expected
```

При падении теста в выводе pytest будет видно, какой именно тест-вектор вызвал ошибку:

```
FAILED test_scoring.py::TestGetScore::test_score_various_combinations[phone=+79991234567 | email=None | ... | expected=1.5]
```

### test_scoring.py

Модульные тесты, покрывающие:

| Класс | Описание |
|-------|----------|
| `TestGetScore` | Тесты расчёта скоринга: все параметры, нет параметров, кэширование, пустые строки, параметризованные комбинации |
| `TestGetInterests` | Тесты получения интересов: с данными, пустые, несуществующий ключ |
| `TestStore` | Тесты Store: инициализация, обработка ошибок в cache_get/cache_set |
| `TestStoreWithMockRedis` | Тесты Store с мокированным Redis: get, set с TTL, set без TTL, cache_get |

## Deadline
Задание нужно сдать через неделю. То есть ДЗ, выданное в понедельник, нужно сдать до следующего занятия в понедельник. Код, отправленный в это время, рассматривается в первом приоритете. Нарушение делайна (пока) не карается, пытаться сдать ДЗ можно до конца курса. Но код, отправленный с опозданием, когда по плану предполагается работа над более актуальным ДЗ, будет рассматриваться в более низком приоритете без гарантий по высокой скорости проверки
