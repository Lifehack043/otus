# Hacker News Async Crawler

Асинхронный краулер для новостного сайта [news.ycombinator.com](https://news.ycombinator.com).

## Описание

Краулер запускается каждые N секунд, парсит топ новостей, сохраняет каждую новость, а также сохраняет все ссылки из обсуждения конкретной новости.

## Функциональность

- **Асинхронный парсинг** — использует `asyncio` и `aiohttp` для параллельных запросов
- **Топ новостей** — извлекает заголовок, URL, рейтинг, автора, время и количество комментариев
- **Ссылки из обсуждений** — для каждой новости парсит страницу обсуждения и собирает все уникальные внешние ссылки
- **Периодический запуск** — краулер запускается циклически с настраиваемым интервалом
- **Сохранение в JSON** — результаты каждого цикла сохраняются в отдельный JSON-файл с timestamp
- **Повторные попытки** — автоматический повтор запросов при ошибках с экспоненциальной задержкой

## Установка

```bash
pip install -r requirements.txt
```

## Использование

### Периодический режим (по умолчанию)

```bash
python crawler.py
```

Краулер будет запускаться каждые 60 секунд (по умолчанию).

### Однократный запуск

```bash
python crawler.py --once
```

Выполняет один цикл краulin'а и завершается.

## Конфигурация

Параметры настраиваются через переменные окружения:

| Переменная | Описание | Значение по умолчанию |
|---|---|---|
| `CRAWL_INTERVAL` | Интервал между запусками (секунды) | `60` |
| `OUTPUT_DIR` | Директория для сохранения результатов | `./data` |

Пример:

```bash
CRAWL_INTERVAL=120 OUTPUT_DIR=./results python crawler.py
```

## Структура выходных данных

Каждый цикл краulin'а создаёт файл `hackernews_YYYYMMDD_HHMMSS.json` в директории вывода:


## Архитектура

```
crawler.py          # Основной модуль краулера
requirements.txt    # Зависимости проекта

└── ...
```

### Классы

- **`NewsItem`** — модель одной новости с полями: заголовок, URL, рейтинг, автор, время, комментарии, ссылки
- **`HackerNewsCrawler`** — основной класс краулера с методами:
  - `fetch_page()` — асинхронный запрос страницы с повторными попытками
  - `parse_main_page()` — парсинг главной страницы
  - `parse_discussion()` — парсинг страницы обсуждения
  - `crawl_once()` — один полный цикл краulin'а
  - `save_results()` — сохранение в JSON
  - `run_periodically()` — периодический запуск

## Зависимости

- **aiohttp** — асинхронный HTTP-клиент
- **beautifulsoup4** — парсинг HTML
- **lxml** — быстрый HTML-парсер для BeautifulSoup
